# emrebulut.tech

Kişisel portfolyo sitem — Elektrik-Elektronik Mühendisliği öğrencisi olarak
projelerimi, deneyimlerimi ve yetkinliklerimi topladığım yer.

**Canlı:** [emrebulut.tech](https://emrebulut.tech)

## Kullanılan teknolojiler

Saf HTML, CSS ve JavaScript — build adımı veya bağımlılık yok.

- Türkçe / İngilizce dil desteği (istemci tarafı, `data-i18n` ile)
- Video arka plan, scroll animasyonları, açılır proje detayları
- Mobil uyumlu (responsive) tasarım

## Yapı

```
index.html          # Tüm sayfa içeriği
assets/
  css/style.css     # Tasarım sistemi (CSS değişkenleriyle)
  js/script.js      # Çeviriler, animasyonlar, etkileşimler
  images/           # Kurum logoları
  video/            # Arka plan videosu
  cv/               # CV (PDF)
```
